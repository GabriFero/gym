# IRONSTACK

Sito ecommerce Next.js per un brand di integratori da palestra: proteine, creatina, pre workout, elettroliti e bundle performance.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- pnpm

## Avvio locale

```bash
pnpm install
pnpm dev
```

Apri `http://localhost:3000`.

## Comandi

```bash
pnpm lint
pnpm build
```
